1. Restricted Sections:
Wikipedia restricts crawling in areas such as edit histories, special administrative pages, talk pages, API query endpoints without proper parameters, and dynamic search interfaces (e.g., /w/index.php, /wiki/Special:).

2. User Agent Rules:
Yes, specific user agents like Googlebot, Bingbot, and custom crawlers have tailored rules. Some aggressive bots are completely disallowed, while polite crawlers are permitted on general content pages.

3. Reflection on Purpose of robots.txt:
Websites use robots.txt to define crawling boundaries, prevent server overload, and protect sensitive or non-public pages from being indexed. It promotes ethical scraping by establishing clear consent guidelines between site owners and automated tools, ensuring crawlers consume resources responsibly without disrupting service for real human users....
